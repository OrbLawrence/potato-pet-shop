## 已做的脱敏

- Dify / OSS / JWT / 数据库凭据全部替换为环境变量占位符。
- 手机号、门店电话、地址、姓名替换为演示值。
- 局域网 IP 替换为示例网段。
- 移除演示环境硬编码兜底管理员账号。
- 数据库只保留 DDL，删除全部 `INSERT` 数据与默认密码。
- 小程序图片地址替换为 `https://cdn.example.com/...`。

## 不能直接运行

本目录缺少：

- 实体类、Mapper 接口、部分 DTO。
- 完整 `application.yml` 与 `.env`。
- 前端静态资源、小程序静态图片。
- 部署脚本与 Nginx 配置。

如果你要在自己的完整工程中运行，请参考 `docs/09-本地运行与部署.md`，并注入自己的数据库、Redis、Nacos、Dify 与 OSS 配置。
