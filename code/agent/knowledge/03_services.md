# 服务项目与价格参考

## 洗护美容

### 基础洗护

- 小型犬基础洗护：68 元起。
- 中型犬基础洗护：98 元起。
- 大型犬基础洗护：158 元起。
- 猫咪基础洗护：88 元起。
- 兔子基础洗护：88 元起。

### 美容造型

- 狗狗局部修剪：根据犬种、体型和毛量评估，具体价格到店确认。
- 猫咪剃毛、去浮毛：根据毛发状态评估，具体价格到店确认。
- 宠物 SPA：以门店现场项目为准。

### 洗护注意事项

- 洗护前会检查皮肤、耳道、指甲和肛门腺状态。
- 年龄过小、疫苗未齐全、生病或刚手术的宠物暂不建议洗护。
- 特殊犬种或攻击性较强的宠物，请提前告知，方便安排单独服务。

## 宠物寄养

- 小型宠物寄养：68 元/晚起。
- 中型宠物寄养：88 元/晚起。
- 大型宠物寄养：128 元/晚起。
- 寄养费用包含基础粮、饮用水和每日状态记录，具体以门店确认为准。
- 寄养需提供有效疫苗记录；如宠物需服药，请提前说明并提供药物与剂量。

## 健康体检

- 基础健康体检：199 元起。
- 体检内容通常包括体温、体重、皮肤被毛、耳道、口腔、心肺听诊等基础项目。
- 具体套餐和检查项目以门店现场说明为准。

## 疫苗与驱虫

- 门店可提供疫苗、驱虫咨询与预约，具体品牌和价格以门店现场为准。
- 疫苗和驱虫前需了解宠物年龄、体重、健康状况及既往免疫史。

## 宠物行为训练

- 提供基础服从、定点排便、社会化等训练咨询。
- 训练周期和费用需由工作人员评估后报价。

## 上门服务

- 部分门店可提供上门喂猫、上门遛狗等预约服务。
- 上门服务范围、时段和费用以门店实际覆盖区域为准。

## 价格说明

以上价格均为参考价格，最终价格以门店现场或电话确认为准。
