# 会员与充值说明

## 会员账户

土豆宠物之家用户客户端支持会员注册与登录，会员账户可在线上浏览宠物与门店信息、查询余额、
办理充值、修改个人资料和修改密码。

## 充值用途

- 账户余额可用于门店洗护、寄养、用品购买等消费。
- 线上充值金额需到店使用。
- 线上展示的“微信支付”和“支付宝”仅为参考支付方式，亦可线下充值。

## 充值流程

1. 用户进入“账户充值”页面，选择充值金额或输入自定义金额。
2. 选择支付方式：微信支付或支付宝。
3. 确认支付后生成充值订单，页面显示支付中状态。
4. 支付成功后，订单状态变为成功，账户余额增加对应金额。
5. 用户可在“充值记录”中查看历史订单。

## 余额说明

- 充值成功后余额实时更新。
- 当前版本充值不设置优惠、赠送或满减逻辑。
- 余额仅作为账户数字资产，不对接真实资金结算。

## 个人信息与密码

- 用户可修改手机号、地址等个人资料。
- 用户可通过原密码验证后设置新密码。
- 如忘记密码，请联系门店工作人员协助处理。

## 预约与取消

- 洗护、寄养等线下服务建议提前预约。
- 如需取消预约，请尽早联系对应门店。
- 具体预约取消规则以各门店说明为准。
