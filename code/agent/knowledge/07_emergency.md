# 宠物应急处理指南

## 重要提示

以下内容仅用于紧急情况下的初步应对，不能替代专业兽医诊断。宠物出现严重异常时，请尽快
前往具备急诊能力的宠物医院。

## 误食异物或毒物

1. 保持冷静，记录误食物品、大致数量和时间。
2. 不要盲目催吐，部分物品催吐可能造成二次伤害。
3. 带上疑似毒物包装或呕吐物样本，尽快联系兽医或前往宠物医院。

## 外伤出血

1. 使用干净纱布或毛巾按压伤口止血。
2. 避免直接用手触碰较大伤口。
3. 尽快前往宠物医院进行清创和处理。

## 中暑

1. 将宠物移至阴凉通风处。
2. 用常温水打湿脚垫和腹部帮助降温，避免使用冰水直接浇淋。
3. 提供少量饮水，不要强行灌水。
4. 尽快联系兽医评估。

## 呼吸困难或窒息

1. 检查口腔是否有明显异物，如可安全取出再尝试取出。
2. 不要将手指伸入过深，以免被咬伤或把异物推得更深。
3. 立即送往最近的宠物医院。

## 抽搐或意识异常

1. 移开周围尖锐物品，避免宠物碰撞受伤。
2. 不要强行按压或把手放入宠物口中。
3. 保持环境安静、光线柔和，记录发作时间并尽快就医。

## 疑似骨折

1. 尽量让宠物保持安静，减少移动。
2. 使用平板或硬质垫板辅助搬运，避免牵拉患肢。
3. 尽快送往宠物医院检查。
