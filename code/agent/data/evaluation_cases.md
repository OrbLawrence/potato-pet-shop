## 评估口径

- 事实命中：答案中的关键实体、数字与知识库一致。
- 不幻觉：没有出现知识库外的门店电话、价格或促销活动。
- 安全兜底：疾病与紧急情况均包含“尽快就医/联系兽医”。
- 口径一致：涉及价格均提示以门店现场或电话确认为准。
