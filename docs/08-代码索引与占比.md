- **Agent 60.0%**：Agent 模块的“代码”本身只有导入脚本 + Chatflow 配置；知识库 7 篇文档只展示 4 篇节选。

## 4. 选段理由

### 4.1 后端

- `JwtAuthenticationFilter` + `JwtTokenProvider`：说明网关如何统一鉴权、如何注入可信用户头。
- `LoginController`：说明双角色登录与改密；已移除硬编码兜底账号。
- `RechargeService`：说明“先建单、后支付”、行锁、幂等入账。
- `ProductOrderService`：说明下单事务、条件扣库存、条件扣余额、核销码。
- `ProductService`：说明 Redis Cache-Aside 与主动失效。
- `DifyChatService`：说明 SSE 转发、事件协议、思考过滤。
- `application.yml`：说明配置如何通过环境变量注入，全部为占位符。

### 4.2 前端

- `router/index.js`：路由表 + 角色守卫 + CRUD 配置，是管理端结构的缩影。
- `utils/request.js`：Axios 拦截器与 401 处理。
- `utils/aiStream.js`：Web 端 SSE 解析。
- `Layout.vue` / `UserLayout.vue`：两种角色的布局差异。
- `Dashboard.vue`：ECharts 数据看板。
- `ProductOrders.vue`：订单查询与核销。
- `UserAI.vue`：聊天 UI 与流式渲染。
- `Login.vue`：双角色登录与表单校验。

### 4.3 小程序

- `shop/index.vue`：商品、购物车、门店、支付、订单的完整购买流程。
- `ai/index.vue`：流式问答、停止生成、新对话、阻塞降级。
- `utils/ai.js`：`enableChunked` 分块解析。
- `utils/request.js`：统一请求与 401 处理。
- `profile/index.vue`：个人中心入口。

### 4.4 Agent

- `system_prompt.md`：回答边界与安全规则。
- `chatflow_config.yml`：检索 → LLM → 回答的最小闭环。
- `import_to_dify.py`：知识库自动化导入。
- 4 篇知识库节选：门店、服务、充值、应急。
- `evaluation_cases.md`：评测口径。

## 6. 如何阅读代码

1. 先看 `code/README.md` 了解目录与脱敏规则。
2. 按“网关 → 用户服务 → 商品服务 → AI 服务”的顺序读后端。
3. 前端先读 `router/index.js` 与 `utils/request.js`，再读具体页面。
4. 小程序先读 `utils/request.js` 与 `utils/ai.js`，再读 `pages/shop/index.vue`。
5. Agent 先读 `system_prompt.md` 与 `chatflow_config.yml`，再看 `DifyChatService.java`。
